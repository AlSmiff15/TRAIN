 Apple Health import

Import running, cycling, swimming, strength and other workout sessions recorded in Apple Health. Import happens entirely on your iPhone and does not send your data anywhere. This is a manual import, not an automatic HealthKit connection.

On iPhone: Health app → Summary → profile picture → Export All Health Data → Save to Files. In Files, tap the exported ZIP to unzip it, then open the apple_health_export folder and select export.xml below.

Supports XML exports. ZIP files must be unzipped first. Re-importing the same workouts will not duplicate them.

Choose an earlier date to import more history. Only workout sessions are imported, not medical records or other health information. Average heart rate may not be present in the Apple export's workout summary.

🔒 Password protected backup

Encrypted backups protect your workouts, recovery check ins, morning readiness, training blocks and preferences. Encryption and decryption happen on this device. The password is never uploaded or saved. Keep it safe: there is no password reset.

Use the password above to unlock a backup. Restoring merges workouts and lets you choose whether to restore other records.

Privacy note: This protects exported backup files, but it does not encrypt the app’s everyday local browser storage. Anyone with access to your unlocked iPhone or browser profile may be able to access stored records.

Unencrypted export / compatibility

Warning: JSON and CSV files are not encrypted. Only use these if needed, and keep them private. Export a backup regularly, especially before clearing Safari website data or changing iPhones. Imported JSON backups replace or merge saved entries by ID.

Automatic saving & offline storage

Each saved workout, check in, training block and preference change is saved automatically on this iPhone. TRAIN keeps a second local database copy where supported. There is no cloud backup. Export an encrypted backup regularly.

Using on iPhone

For reliable saved data, run this HTML page from a website using HTTPS, then open it in Safari and choose Share → Add to Home Screen. If opened directly from Files, browser storage and Home Screen behaviour may vary. It does not connect directly to HealthKit. Apple Health workouts can be imported manually above.

📱 Add TRAIN to your Home Screen

Open your hosted TRAIN website in Safari, tap Share, then Add to Home Screen → Add. TRAIN will launch in its own full-screen window. Entries save automatically on this device. For recovery after losing your phone, keep an encrypted copy in iCloud Drive.

Before switching from your old version, export your JSON backup there and import it in this installed version. Saved data does not transfer automatically between addresses or browsers.
